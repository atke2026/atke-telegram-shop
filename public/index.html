Reseller API integration

Build and verify entirely with a sandbox key. Change only the key to switch your tested integration to live fulfilment.

1
Create a sandbox key

Open API keys, generate a sandbox key, and save it securely. The full secret is displayed once. Never put it in browser code, a mobile app, logs, or a public repository.

Sandbox uses simulated funds and fake delivery data. Live uses your normal YeneShop wallet and fulfils real orders.
2
Authenticate every request

The base URL is https://yeneshop.amixmon.com/api/reseller/v1. Send your key in the Bearer authorization header on every request.

curl "https://yeneshop.amixmon.com/api/reseller/v1/products" -H "Authorization: Bearer YOUR_SANDBOX_KEY"
3
Load the available products

Always obtain product IDs, current reseller prices, availability, stock, delivery type, and customer-input requirements from this endpoint.

resellerPrice: The amount deducted from your wallet.
suggestedRetailPrice: YeneShop's customer-facing retail price.
customerInput: If present, collect this required value from your buyer.
deliveryType: Either instant delivery or manual fulfillment.
4
Create an order

Generate a unique externalId in your system and keep it with your customer order. It may contain letters, numbers, dots, underscores, colons, and hyphens, up to 100 characters.

5
Save and fulfil the result

Store the returned order id, status, price, and delivery data. A manual product can return awaitingDelivery: true; poll the order until it is completed.

deliveredItems: Credentials, links, codes, or other delivered values.
instructions: Product redemption guidance returned after purchase.
balance: Your remaining environment balance after the order.
curl "https://yeneshop.amixmon.com/api/reseller/v1/orders" -X POST -H "Authorization: Bearer YOUR_SANDBOX_KEY" -H "Content-Type: application/json" -d '{"externalId":"ord_sample_01","productId":1}'
All endpoints
GET /balance Current live or sandbox balance
GET /products Your current reseller catalogue
POST /orders Create or safely retry an order
GET /orders List the latest 50 orders
GET /orders/:externalId Look up one order from your reference
Errors and safe retrying
400 — invalid fields or required customer input is missing
401 — the API key is missing, invalid, rotated, or revoked
403 — reseller access is suspended or the account is blocked
404 — an order or product was not found
409 — the external ID was already used with different order data
422 — insufficient balance or the product is out of stock
5xx / timeout — retry with the exact same external ID and body.
